# Estadística interactiva · Interactive Statistics

Mapa interactivo de probabilidad y estadística, con puentes al aprendizaje profundo. Pensado para repasar en el iPad (se puede instalar en la pantalla de inicio y funciona sin conexión) y como material de repaso para estudiantes de Deep Learning.

An interactive map of probability and statistics, with bridges to deep learning. Designed for review on the iPad (installable to the home screen, works offline).

**Web:** https://jperezaracil.github.io/estadistica-interactiva/

## Desarrollo

```bash
npm install
npm run dev      # servidor local
npm run build    # compila el sitio y el service worker en dist/
```

El despliegue a GitHub Pages es automático al subir a `main` (GitHub Actions).

Las explicaciones son originales. Las referencias remiten a Wilks (2019), *Statistical Methods in the Atmospheric Sciences*, y Murphy (2022, 2023), *Probabilistic Machine Learning*.
